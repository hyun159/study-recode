# 이해한 내용

```
리눅스의 모든 프로세스는 결과값으로 리턴코드를 남긴다.
0 - success
그 외 - failed

엔서블도 모듈이 실행되면 JSON 객체를 반환한다.
키 값은 rc, stdout, stderr, changed 형태로 되어있다.

register는 JSON 객체를 변수에 저장하는 디렉티브다.

handler의 notify는 JSON 객체의 changed 값을 참조한다.
따라서 해당 모듈의 JSON의 changed 값이 true라면 notify가 실행된다.


- 사용 예시 -

register: test
test.rc
test.stdout

# 리턴 코드가 2일 때만 실패해라
failed_when: test.rc == 2 

```
